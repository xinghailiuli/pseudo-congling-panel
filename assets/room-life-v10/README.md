# 日常动作图集

`bed`、`sofa`、`desk`、`garden`、`upper`、`carry`、`cover` 为 AI 辅助制作的完整角色动作图集，`greenhouse.png` 为园艺场景接触层。运行时以 `room-life-v11/geometry.json` 与 `src/room-life-sequences.mjs` 定义的校准参数为准；本目录原几何数据保留作素材说明。

动作包括坐卧、持物、园艺、阅读和床铺等，不是 3D 骨骼。衍生素材遵循根目录 `THIRD_PARTY_NOTICES.md` 的非商用与署名条件。角色来源：[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)。
