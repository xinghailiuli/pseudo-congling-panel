# 琉璃衣柜 v1

13 套去重参考服装，208 个基础姿态。原始透明 PNG 不做像素改写，`geometry.json` 用裁切范围和轮廓将整张图集拆为可显示的角色姿态。

这是一组完整人物素材，不是可直接叠在原角色上的独立衣服层，也不是 3D 模型。原装详细动作仍独立保留。新装使用基础姿态和四帧步行循环，沿用房间的行走路径、楼梯连接、活动时钟、隐藏暂停和摸头暂停；没有逐帧复刻原装全部动作（例如精细工具交换、盖被翻身）。

## 文件

- `catalog.json`：稳定服装 ID、名称、参考来源。
- `<id>.png`：透明16姿态图集。内置 imagegen 生成。
- `geometry.json`：只读分析 PNG alpha 得到的裁切、轮廓、尺寸。
- `references/`：用户提供的源参考。重复礼服只留清晰的第5张版本。
- `generation.json`：生成提示词及来源记录。
- `index.html`：服装总览，可点击查看整张图集。

## 姿态索引

0正面、1左侧、2背面、3右侧；4–7左向行走；8写字、9坐姿/打字、10阅读、11零食；12侧躺、13趴卧、14浇水、15附魔。

## 接入

构建时每套资源独立打包为 `lib/client.wardrobe-<id>-v1.js`，在“她的房间 → 衣柜”选择后按需加载。素材校验和图片解码成功才替换当前造型；失败保留原造型。选择保存在宿主独立的 `liuli-companion:wardrobe:v1` localStorage 键，选择原装可恢复原角色。

新装功能没有修改服务端状态字段、19件房间物品、QQ、日记、记忆或游戏接口。原装图集和其他插件保持独立。原生界面最终视觉验收由用户完成。
