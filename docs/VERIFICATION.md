# 1.11 优化版（1.1.1）发布验证

验证日期：2026-11-01。Windows、Node.js 24；DSH 适配基线 0.2.0-rc.2。发布准备使用独立源码与解包目录，不操作使用者的原生 DSH 界面。

## 验证项目

- 构建主客户端、房间图像、生活动作及全部服装资源块；当前使用 v19 生活/服装载荷，并保留兼容块。
- 公开版完整测试 **205 项通过，0 失败、0 跳过**；覆盖步态、房间路线、上下床中断退出、全服装载荷、房间状态恢复、局部手部动作、公开版数据和资源移植。
- 1,122 张 PNG/WebP 的完整性清单逐文件核对大小及 SHA-256；包括 965 帧原装角色。
- 源码构建生成的 13 套服装、71 个当前及兼容懒加载块均可解析；安装包保留其中 30 个当前及 1.1 公开版兼容块；文档链接和公开内容扫描检查本机绝对路径、凭据及私人文件。
- 解包后从包内入口启动，默认房间 19 件物品、22 条图片路由可读取；未配置外部桥接时测试不发出网络请求，关闭后卸载路由。
- 已有自定义房间和故意清空的房间不重新填充默认家具；主包名和数据位置保持原有公开版约定。
- 独立复核发现动作预览入口仍引用旧资源，已改为 v19，并加入页面引用与路由对应检查；关于页版本显示也已校正。
- 发布过程校验本机现用插件 1,316 个文件未修改；不调整其他插件、布局或浏览器存储。

安装包按运行依赖精简重复构建文件，所有图片路由与当前生活/服装载荷均需通过解包检查。源码 ZIP 保留全部原始素材，执行 npm run build 后可恢复所有构建块。最终测试数量和安装包/源码 ZIP 的字节校验记录随发布说明提供；仓库测试与 assets/asset-integrity.json 可以复现检查，下载件校验使用附件 SHA256SUMS.txt。

## 隔离动作检查与边界

本次更新在本机安装时通过 195 项测试；公开版还包含额外的打包、独立运行和预览检查。此前使用同版房间代码在隔离浏览器中，对原装及全部 13 套服装执行起床、走向电脑、返回上床，并检查睡眠/踢被子和 24 姿态总览。

这些检查不等于真实 DSH 安装、鉴权、全部动画流畅度和服装接触位置已验收。本版保留 Pre-release 标记。角色仍使用 2D 分帧与局部变形，不宣称无任何穿模。

文档截图来自隔离环境，不包含真实聊天内容。没有发送 QQ 消息、操作 Minecraft 或修改开机启动。QQ、模型、记忆和日记服务需要使用者自己的配置，本轮未进行真实外部联调。

动作和参考图接触位置以默认 19 件物品组合为基准；改变房间物品清单后使用独立物品绘制兼容模式。服装新增了床铺、步态和书桌动作，其余持物细节尚未覆盖原装全部细分动画。
