验证日期：2026-11-01。环境：Windows、Node.js 24.19.0。DSH 适配基线为 0.2.0-rc.2。本次在公开源码副本和解包目录进行验证，没有重新安装或操作正在使用的 DSH。

## 已完成

- `npm run build` 成功；构建入口包含家具工作区、衣柜与本地时段窗景，完整资源按需加载。
- `npm test`：**177 项通过，0 失败、0 跳过**。涵盖动作/路径、衣柜姿态、工作区、时区、加载隔离、数据并发与公开版移植。
- 独立只读复核完成；关于页遗留的旧版本与素材许可说明已修正，并重新构建。
- **1,009 张图片**逐文件大小与 SHA-256 匹配：965 帧原角色 WebP、44 张房间/动作/服装 PNG。
- **13 套服装**与 16 个懒加载块完整；其中 15 个当前预览载荷可读取，保留的 v7 兼容块也通过语法及内容检查。
- `.tgz` 解包后从包内 `lib/index.js` 启动：默认房间有 **19 件物品**，22 条图片路由均返回可读取内容。未配置桥接的测试中对外网络调用为 0，关闭时路由全部卸载。
- 公开版测试逐个读取全部 965 帧角色路由，并检查鉴权、路径穿越和请求方法限制。
- 已有自定义或故意清空的房间保持原样；不因启动重新填充家具。
- 源码与包内文本扫描未发现作者绝对路径、实际凭据或对独立桌宠插件的运行依赖；私人状态、参考图片、生成回执及其他插件未纳入文件清单。文档本地链接检查通过。
- 逐文件校验现用插件 **1,134 个文件未修改**。发布在独立目录进行，未修改其他插件布局或浏览器存储。

测试原始输出保存在发布准备目录；仓库内的 `test/`、`test-client.mjs` 与 `assets/asset-integrity.json` 可用于重现自动化验证。发布页 `SHA256SUMS.txt` 用于验证下载的安装包和源码 ZIP。

## 边界与已知限制

- **真实 DSH 安装、鉴权、最终画面/动作观感及跨平台表现仍待使用者验收**，因此此版标为 Pre-release。自动化与隔离检查不等于原生视觉验收。
- 文档截图来自此前同版功能的隔离场景与虚构数据；没有把它们冒充本机真实账号或真实聊天内容。
- 新服装是每套 16 个基础姿态加局部动态，尚未逐套覆盖原装角色全部持物细节。动作位置和遮挡已做校准，仍欢迎反馈特定衣服/动作下的问题。
- 参考图插画与精细接触动画依赖默认 19 件物品组合；改变物品清单后会使用独立物品绘制兼容模式。
- 外部 QQ、模型、记忆和日记服务未进行真实联调；本次未发送 QQ 消息、操作 Minecraft 或改动开机启动。
- 系统诊断个别来源标签仍保留 `QQWhale-Diary` 等历史名称，不代表已接入。实际配置状态以 `bridgeConfigured` 和连接检查结果为准。
