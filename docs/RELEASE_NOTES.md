# 1.3 完全重制版（1.3.0）

本次汇总 v1.2.0 之后的小屋与交互重制，完整包可以直接安装。

- 星海回响 HUD：发光鲸鱼、清晰标题、胶囊导航、三张信息卡；1080p / 2K 共用比例规则。
- 11 项生活动作使用紧凑面板，保留小屋实时视野；修复动作切换、沙发退出、遮挡和资源加载异常。
- 侧边更衣室，原装加 13 套服装，试穿、收藏、保存和随机搭配；优化换装加载与解码。
- 书架支持原创短篇及 TXT / Markdown / 无加密 EPUB 导入，阅读进度独立保存。
- 精力随睡眠、休息和工作变化；心率随活动模拟变化，并明确标注模拟。
- 模块化按需加载、资源缓存与失效重试、隐藏页面暂停、截图导出优化、花海岛场景隔离。
- 143 张交付图片无损压缩，原始 RGBA 一致，源码保留原图；同口径候选 ZIP 减少 18.41%。
- 公开包恢复独立启动，不依赖作者机器路径、其他角色插件或 QQ 桥接。

**下载**：普通用户选 dsh-whale-status-1.3.0.tgz；开发选 source.zip；小黑盒配图和文案选 showcase.zip。SHA256SUMS.txt 用于校验。

升级前备份现有配置和数据。保留插件身份与本地存储；如旧宿主缓存导致资源 404，等任务结束再正常重启 DSH。

发布源代码构建及 390 项测试通过。展示图来自隔离环境实际渲染，使用示例数据；不等同于全部设备的原生 DSH 验收。房间是 2D 分层动画，心率不是传感器数据。
