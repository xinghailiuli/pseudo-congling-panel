# 伪从绫开始的面板 1.0

琉璃陪伴中心完整套件：14 个页面、MC 风格 14 × 10 双层小屋、19 件默认物品、大肥鱼 965 帧角色素材、九种生活活动与摸头交互、上下楼过渡和露台直达路线。

仅安装一个 `dsh-whale-status` 面板。角色素材随包提供，无需另外安装桌宠插件。未包含其他插件或私人数据。

下载 `dsh-whale-status-1.0.0.tgz`，在下载目录运行：

```powershell
dsh plugin --profile desktop add ./dsh-whale-status-1.0.0.tgz
```

完整页面和适配代码都包含；QQ、人格、长期记忆、日记和模型生成需使用者自行接入相应外部服务，详见 README 与接入说明。

提供构建、离线测试、打包后独立启动/素材读取检查。实际 DSH 界面安装和动画观感由发布者手动验收；未声称跨平台全面验收。
