# 把鲸鱼小屋重新做了一遍：1.3 完全重制版更新！

自 1.3 起，项目由「伪从绫开始的面板」正式更名为「星海回响」。本次以作者 xinghailiuli 的独立作品名称发布，版本名称为「星海回响 1.3 · 完全重制版」。为兼容旧版升级，仓库地址与插件 ID dsh-whale-status 继续沿用，已有数据和设置保持保留。

《星海回响》1.3 完全重制版来了。这次把上一版之后的小屋界面、换装、生活交互和底层加载一起整理了一遍。

最直观的变化是新的「星海回响」界面：发光鲸鱼、蓝紫色环绕导航、分段信息卡和底部状态胶囊。1080p 和 2K 使用同一套比例规则。

【配图 1：01-living-room.png】

之前的大面板容易挡住小屋，这次把生活动作改成了底部紧凑面板，可以一边看她在房间里活动，一边切换操作。11 项生活动作继续保留，也修了动作退出、沙发休息、桌椅遮挡和上下床衔接等问题。

【配图 2：02-action-tray.png】

更衣室也重新做了：侧边是试衣舞台，旁边仍能看到小屋。原装加 13 套服装，支持收藏、保存穿搭和随机搭配。重复的动作预览去掉了，换装资源改为按需加载，并补了快速切换时的保护。

【配图 3：03-dressing-room.png】

精力条现在会真的跟着活动增减：睡觉、沙发休息会恢复，写字、打字、散步会消耗；点击能看到当前状态与变化速率，关掉再打开也会保留。心率同样会变化，不过它是角色的模拟心率，不是现实测量数据。

【配图 4：04-bedroom.png】

书架加入了原创短篇，也支持导入 TXT、Markdown 和无加密 EPUB，能翻页、续读并单独保存阅读记录。花海岛页面的样式和切换流程也做了修复。

这次还整理了模块化和资源加载：拆分可选模块，减少重复加载，处理页面隐藏、缓存和截图导出。143 张图片做了无损压缩，逐张核对像素一致；同一候选完整 ZIP 从 328.32 MB 缩到 267.86 MB，减少约 18.4%。
