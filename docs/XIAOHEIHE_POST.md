# 给大肥鱼的小屋做了个 1.1 更新：能换装、吃零食，电脑也能真的点开了

之前分享的「伪从绫开始的面板」继续更新啦。这次主要折腾琉璃陪伴中心里的 MC 风格双层小屋，希望大肥鱼住进去以后，能多一点生活感。

**先说大家最容易看到的几处变化：**

**1. 沙发终于能多待一会儿了。**

补了坐着、抱膝、侧躺、趴卧、吃零食这些日常动作，也把姿势切换放慢了。离开沙发先起身，园艺结束先收工具，不再每隔一小会儿就换一套动作。

**2. 做了个科技镜衣柜，一口气放了 13 套衣服。**

镜子就在二楼附魔区和小麦温室中间。礼服、卫衣、冬装、女仆、汉服、剑装、水手服都有，原装也能随时切回来。衣柜下面留了预览，选完直接看，还可以试试走路、坐沙发、写字、打字和睡觉。

每套新衣服目前有 16 个基础姿态，加了局部动态。原装角色的精细生活动作更多，新衣服还没做到每个拿工具的小细节都完全一致，这部分后面继续磨。

**3. 把陪伴功能放进家具里。**

点电脑，打开电脑样式的记忆/人格工作台；点附魔台，翻日记书；点床，查看长夜和梦境。对应的重复侧栏入口去掉了，小屋还留在背后，这样家具也更有用途。

**4. 窗外会跟着你自己的时间变化。**

按照使用者电脑的本地时间显示晨、昼、暮、夜，换个时区也跟着走。这个是时段光景效果，没有接真实天气。

**5. 又修了一轮动作和穿模。**

主要是沙发趴卧方向、书桌坐姿、被子遮挡、园艺过道，还有换装预览和主房间同时显示时的遮罩冲突。楼梯、露台路线以及原有 19 件物品也保留着。

这版已经上传 GitHub，先以 **1.1.0 预发布**供大家体验。自动化和隔离检查已做，实际 DSH 里的画面还需要大家试试；如果有问题，带上衣服名字、动作、楼层和截图/短视频，比较好定位。

这是 DeepSeek Harness 的陪伴面板插件，房间本身是 2D 场景。小屋、角色、衣柜随包提供；记忆、日记、QQ 等服务需要自己接入。下载 `.tgz` 安装包就行，安装方法写在仓库首页里。
