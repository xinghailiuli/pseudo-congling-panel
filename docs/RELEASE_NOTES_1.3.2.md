# 星海回响 1.3.2 - 大肥鱼之岛小船重塑、探索舱与流畅度优化版

作者：xinghailiuli。

本版接续 `v1.3.1` 迭代（并将 3D 鲸鱼小岛独立体验命名为 **「大肥鱼之岛」**），重点解决上版码头船体过简、探索目标与高配帧率波动等问题。完整独立离线体验包仅 **19.11 MB**（20,037,852 字节），解压后无需搭建 HTTP 服务，用新版 Edge 或 Chrome 双击 `开始使用.html` 即可离线进入。

- **南码头星海小船立体船体重塑**：告别扁平木板，重做弧线船壳、船肋、靛蓝软垫长凳、船首弯钩暖光提灯、倾斜桅杆风帆与尾流；登船即可环岛巡游，伴随离岸跃水蓝鲸。
- **「星海探索舱」HUD 与多端零重叠排版**：右上角集成声景、手帐、漫步、小船、摄影工坊与时光小屋控制舱，通过 1280x800、522x593、390x844 三端视口 UI 零重叠校验。
- **生态缩放、地面漫步、2K 明信片与 Web Audio 声景**：海鸥/蝴蝶随极速、平衡、精细三档缩放（8/12、18/26、32/44）；地面第一人称漫步与自由飞航按键隔离；5 套胶片滤镜直出 `2048x1152` 明信片；零外部音频依赖合成风浪/天气与互动音效。
- **星海手帐 25 项收集与时光小屋道具**：收录 13 地标 / 6 拾遗 / 6 望远镜抓拍，按亲密度解锁 3 款挂饰；工作区 49 寸带鱼屏 4 套壁纸、专注钟、厨房铜壶煮茶、温室洒水绽放与 5 章栖居志。
- **全面测试与性能调优**：`97/97` 自动化测试全部通过；Edge 真实 WebGL 实测小船巡游 P50 `16.6ms`（GPU `9.69ms`）、极速待机 P50 `23.4ms`、精细待机 P50 `30.0ms`；全流程 `0` console/page 报错、`0` 外部网络请求；离线 ZIP `file://` 双击 `开始使用.html` 启动实测通过。
