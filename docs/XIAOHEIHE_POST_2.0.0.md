# 大肥鱼之岛2.0重塑更新：重做星海小船与全岛探索升级！

盒友们好，我是 xinghailiuli。

上一版 1.3.1 发布后，收到了不少直白的吐槽和建议：尤其是南码头旁边那艘“小船”，放大看简直就是一块扁平木板，太出戏了；另外全岛虽然能漫游和点按地标，但缺少长线探索的目标感，高画质下的帧率波动也还需要压一压。

这轮更新我决定正式定名为《大肥鱼之岛 2.0》，把 2.0 探索舱 HUD、南码头星海小船模型、Web Audio 实时声景、星海手帐收集、地面漫步、2K 摄影工坊、时光小屋道具和全档位性能调度一次性拉满。完整独立离线压缩包仅约 19.11 MB（20,037,850 字节），解压后不用搭任何环境，浏览器双击打开即可直接登岛。

先看最让强迫症舒坦的改动：南码头那艘“板子船”终于推倒重做了！

这次从零雕刻了立体弧线木质船身：曲率船肋、浅木舷缘、带靛蓝软垫的双排实木长凳、船首挂着暖光提灯的弯钩支架、倾斜桅杆配三角帆和星海燕尾旗，停泊在栈道旁能清晰倒映在水面。走到南码头或者点开右上角“2.0 探索舱”的「星海小船」，就能登船开启环岛巡游，顺着海浪绕岛一圈，还会和外海破水跃起的蓝鲸擦肩而过。

顺带也把海岛生态和视角体验补齐了：

离岸海域常驻会跃水喷浪的蓝鲸，海面和花丛里的海鸥、蝴蝶会根据「极速 / 平衡 / 精细」画质档位动态缩放（8/12、18/26、32/44），兼顾氛围和帧率。切进「地面漫步」还能用第一人称沿石板路与木桥贴地逛岛，和自由飞航互不抢键，走到大肥鱼身边随时摸头互动。想留念的话打开「摄影工坊」，内置 5 套胶片滤镜、柔光开关和合照 Pose，一键导出 2048x1152（2K）带时间水印的明信片。

为了把“在岛上住下来”的陪伴感做足，2.0 还加入了声景、手帐和时光小屋细节：

1. 实时 Web Audio 程序化声景与音效：零外部音频文件依赖，晴雨雪风海浪和各种交互动作都有实时合成反馈，切到后台自动平滑静音收敛。
2. 星海手帐 25 项收集：涵盖全岛 13 处地标打卡、6 枚环岛探索拾遗（浅滩海螺、漂流瓶、四叶草、琥珀、陨石、夜光晶），以及观星台上 6 个天文望远镜天体目标抓拍（鲸鱼座、月球、土星环、猎户座、北斗七星、流星辐射点）。收集进度本地持久化保存，随好感度积累还能解锁四叶草发卡、荧光海螺佩和星海小皇冠挂饰。
3. 时光小屋室内道具：同步现实本地昼夜时间段，工作区 49 寸带鱼屏支持 4 套高清壁纸切换和桌面数字时钟/专注计时器；厨房铜茶壶点击可添水煮茶升起热气；东麓玻璃温室一键洒水会有花丛绽放和水雾；二层书廊也收录了 5 章原创《大肥鱼之岛栖居志》。
