# 大肥鱼之岛 2.0 - 独立离线版与星海探索重塑版

作者：xinghailiuli。

自 1.3 起由「伪从绫开始的面板」独立重构为「星海回响」，本次 2.0 正式将 3D 鲸鱼小岛七室一体体验与全新探索玩法命名为 **《大肥鱼之岛 2.0》**。完整独立离线体验包仅 **19.11 MB**（20,037,850 字节），解压后无需安装或搭建 HTTP 服务，用新版 Edge / Chrome 双击 `开始使用.html` 即可离线进入。

- **南码头星海小船立体重构与环岛巡游**：推倒重做原本像平板的木船，雕刻弧线船壳、船肋、软垫长凳、船首弯钩暖光提灯、斜桅风帆与星海燕尾旗；登船一键环岛巡游，伴随尾流与离岸蓝鲸跃水。
- **「2.0 探索舱」HUD 与多端自适应排版**：右上角集成声景、手帐、漫步、小船、摄影工坊与时光小屋入口，并通过 1280x800、522x593 与 390x844 三档视口全界面零重叠断言。
- **离岸蓝鲸生态与分级海鸥蝶群**：按极速 / 平衡 / 精细三档实时调节数量（海鸥 8 / 18 / 32，蝴蝶 12 / 26 / 44），兼顾中低端显卡与高画质观感。
- **地面漫步、2K 摄影明信片与零依赖 Web Audio 声景**：地面第一人称漫步与自由飞航按键隔离；5 套胶片滤镜与柔光开关可直出 `2048x1152` 星海明信片；实时合成晴雨雪风海浪与交互音效。
- **星海手帐 25 项收集与时光小屋互动**：记录 13 处地标、6 处环岛拾遗与 6 个天文望远镜天体目标，随亲密度解锁 3 款大肥鱼饰品；实景同步桌面时钟、49 寸带鱼屏 4 套壁纸、专注钟、厨房铜壶煮茶与玻璃温室洒水绽放。
- **严格测试与性能调优**：97/97 自动化测试 100% 通过；Edge 真实 WebGL 实测小船巡游 P50 `23.4ms`、极速待机 P50 `36.6ms`；全程 `0` console/page 报错、`0` 外部网络请求；独立离线 ZIP 通过 `file://` 双击启动验证。
