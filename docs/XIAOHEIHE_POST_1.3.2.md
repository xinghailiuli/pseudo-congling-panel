# 星海回响1.3.2大肥鱼之岛更新：重塑小船与探索舱上线！

盒友们好，我是 xinghailiuli。

上一版 1.3.1 发布后，收到了不少直白的吐槽和建议：尤其是南码头旁边那艘“小船”，放大看简直就是一块扁平木板，太出戏了；另外全岛虽然能漫游和点按地标，但缺少长线探索的目标感，高画质下的帧率波动也还需要压一压。

这轮我按 1.3.2 小版本做了全面细化并把 3D 鲸鱼小岛正式命名为《大肥鱼之岛》：重塑南码头星海小船立体模型，新增「星海探索舱」HUD、Web Audio 实时声景、星海手帐 25 项收集、地面第一人称漫步、2K 摄影工坊、时光小屋道具，并对全档位流畅度做了专项调优。完整独立离线压缩包依然仅约 19.11 MB（20,037,852 字节），解压后不用搭任何环境，浏览器双击打开即可直接登岛。

一、南码头星海小船重塑：告别平板木板

先看最让强迫症舒坦的改动：南码头那艘“板子船”终于推倒重做了！

这次从零雕刻了立体弧线木质船身：曲率船肋、浅木舷缘、带靛蓝软垫的双排实木长凳、船首挂着暖光提灯的弯钩支架、倾斜桅杆配三角帆和星海燕尾旗，停泊在栈道旁能清晰倒映在水面。

【配图 2：02-boat-closeup.jpg】

走到南码头或者点开右上角「星海探索舱」里的「星海小船」，就能登船开启环岛巡游，顺着海浪绕岛一圈，还会和外海破水跃起的蓝鲸擦肩而过；退出巡游会自动平滑回到原本视角。

二、海岛生态、地面漫步与 2K 摄影工坊

离岸海域常驻会跃水喷浪的蓝鲸，海面和花丛里的海鸥、蝴蝶会根据「极速 / 平衡 / 精细」三档画质实时动态缩放（8/12、18/26、32/44），兼顾中低配置帧率与高画质氛围。

切进「地面漫步」还能用第一人称沿石板路与木桥贴地逛岛（支持 WASD / 方向键与 Shift 加速），和自由飞航互不抢键，走到大肥鱼身边随时摸头互动。想留念的话打开「摄影工坊」，内置 5 套胶片滤镜、柔光开关和合照 Pose，一键导出 2048x1152（2K）带时间水印的星海明信片。

三、声景音效、星海手帐收集与时光小屋

为了让小岛更有“住下来陪伴”的实感，1.3.2 补齐了三套互相联动的本地系统：

1. 实时 Web Audio 程序化声景与音效：零外部音频文件依赖，晴雨雪风海浪和各类互动都有实时合成反馈，切到后台自动平滑静音收敛。
2. 星海手帐 25 项收集：涵盖全岛 13 处地标打卡、6 枚环岛探索拾遗（浅滩海螺、漂流瓶、四叶草、琥珀、陨石、夜光晶），以及观星台上 6 个天文望远镜天体目标抓拍（鲸鱼座、月球、土星环、猎户座、北斗七星、流星辐射点）。本地持久化保存，随好感度积累还能解锁四叶草发卡、荧光海螺佩和星海小皇冠挂饰。
3. 时光小屋室内道具：同步现实本地昼夜时间段；工作区 49 寸带鱼屏支持 4 套高清程序壁纸切换与桌面数字时钟/专注钟；厨房铜茶壶点击可添水煮茶升起热气；东麓玻璃温室一键洒水触发花丛绽放与水雾；二层书廊收录 5 章原创《大肥鱼之岛栖居志》。

四、流畅度调优与全面实测验证

这版针对水面反射调度、接触 AO 缓存、网格批处理和桌面（1280x800）/ 窄侧栏（522x593）/ 移动端（390x844）三端排版零重叠做了专项优化。

实测全部跑通验证：97 项自动化测试 97/97 全部通过（0 失败 0 跳过）；真实 Edge WebGL 环境下，星海小船巡游 P50 帧时 16.6ms（GPU P50 9.69ms，171 DrawCalls），地面漫步 P50 26.6ms，极速 / 平衡待机 P50 23.4ms，精细待机 P50 30.0ms；全流程 0 控制台报错、0 外部网络请求。离线压缩包也做了 file:// 解压双击打开实测：全 15 个交付文件 SHA-256 校验通过，小船巡游与地面漫步均流畅无报错。
